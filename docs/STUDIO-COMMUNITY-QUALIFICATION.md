## Regressions found and addressed

An earlier 510-test run failed in a limb synchronization test while the separate
reference package install was running. Its ten-second entry deadline expired;
cleanup then removed a fixture while a worker was active. Tests now capture
unexpected worker exceptions, check task outcomes, prove stop before cleanup,
and preserve the fixture when stop cannot be proven. The clean full run followed
with the reference installer and qualification Studio stopped.

A separate deterministic test reproduced false Journal corruption when a writer
committed between ledger and replay-index queries. Verification now reads one
SQLite snapshot and preserves refresh invalidation for subsequent foreign commits.
The new test failed before the fix and passes after it. This claim applies to
verification, not an assertion that every public operation is one read transaction.
